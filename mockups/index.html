Obscure Music Theory

Subsets and supersets

  • Constellation

    All 223 classes as one star-map. Pin one and its subsets light up below, its supersets above.

  • Walk

    One class in the middle. Add a note and you go up, remove one and you go down, leaving a trail.

  • Rings

    Grow a set one note at a time. Every note you add becomes a new ring, like a tree trunk.

  • Fingerprint

    Type a set and see every class inside it, or around it, as a strip for each size. Darker means more copies.

  • Overlap

    Two sets as a Venn diagram. Slide one across the other through all 24 transformations to find where it fits.
